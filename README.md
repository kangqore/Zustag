# ZUSTAG (Kangqore Group)
### Hyperlocal Fashion Quick-Commerce & Omnichannel Showroom Network

> **⚡ 30-Minute Showroom Delivery &bull; 10-Minute Doorstep Try-On &bull; Jamshedpur & Gamharia**

ZUSTAG connects premier physical fashion retail showrooms (*Manyavar, Peter England, Zudio, Levi's, Soch, Bata, Fabindia, Westside*) with instant hyperlocal fulfillment, AI-powered occasion styling, multimodal visual search, and cross-brand size prediction.

---

## 🌟 Core Feature Matrix

### 🤖 1. Gemini AI Intelligence Suite
- **Gemini AI Stylist & Lookbook Concierge**: Conversational occasion reasoner generating 3-piece coordinated outfit bundles with 15% instant combo savings.
- **"Snap & Match" Multimodal Visual Search**: Upload photos from Instagram/Pinterest to find nearest in-stock showroom dupes with 96% visual similarity matching.
- **"Smart Fit AI" Cross-Brand Sizing Predictor**: Cross-brand size translation matrix (*Zara/USPA ➔ Manyavar/Levi's*) with automatic Doorstep 2-Size Try-On courier pairing.
- **Smart Weather & Occasion Feed**: Real-time adaptive merchandising responding to Jamshedpur weather (28°C), time of day, and city festive surges.

### 🏬 2. Omnichannel Showroom Ecosystem
- **Virtual Showroom Storefronts**: Browse verified local retail outlets across P&M Mall, Bistupur Boulevard, Sakchi High Street, and Gamharia Industrial hub.
- **Omnichannel Showroom Locator**: Live store hours, contact info, GPS directions, and 30-min doorstep try-on delivery triggers.
- **6-Column Occasion & Brand-First Mega Menu**: Comprehensive occasion and showroom cluster navigation.

### 💎 3. Loyalty & Quick-Commerce UX
- **Zustag Greencard / Club Pass**: Live loyalty points balance, VIP status banners, 1-click points redemption, and 5% cashback on orders.
- **10-Minute Doorstep Try-On Guarantee**: Couriers wait at doorstep while customers try on items before confirming payment.
- **Live GPS & CCTV Route Tracking**: Real-time rider vector tracking with verified showroom packaging assurance.

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.x
- npm / npx

### Installation & Local Run
```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Access web application
open http://localhost:3000
```
